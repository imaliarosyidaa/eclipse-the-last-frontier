Anda adalah seorang Senior Frontend Engineer, UI/UX Designer, Creative Developer, dan Interactive Web Experience Designer yang berpengalaman dalam membuat website promosi game bergaya AAA.

Saya ingin Anda membangun sebuah website promosi game untuk kompetisi dengan tema:

"Immersive Gaming Experience Through Web Technology"

Kriteria kompetisi:
1. Website merupakan website promosi game.
2. Game dapat berupa game orisinal, fan-made showcase, konsep game masa depan, mobile, PC, console, RPG, MMORPG, FPS, MOBA, atau genre lainnya.
3. Website minimal memiliki halaman:
   - Home
   - Character / Hero
   - Gameplay / Features
   - News / Event
   - Download / Play Now
4. Website wajib memiliki unsur interaktif:
   - Animasi
   - Scroll effect
   - Transition
   - Video trailer
5. Website harus memberikan pengalaman pengguna yang menarik, interaktif, modern, dan imersif seperti website promosi game modern.
6. Dilarang menyalin secara langsung desain, source code, maupun aset dari website game lain.

==================================================
1. TUJUAN UTAMA
==================================================

Buat website promosi game yang tidak terasa seperti website informasi biasa.

Website harus membuat pengunjung merasa sedang "memasuki dunia game".

Prinsip utama:

DO NOT BUILD:
- website dengan sekadar navbar + hero + cards + footer
- landing page statis
- kumpulan card tanpa storytelling
- animasi berlebihan yang tidak memiliki tujuan
- template SaaS
- dashboard
- website corporate

BUILD:
- cinematic game promotional website
- immersive storytelling
- interactive world
- character showcase
- cinematic transitions
- scroll-driven storytelling
- interactive gameplay presentation
- futuristic UI
- strong visual hierarchy
- memorable first impression

24. RESPONSIVE DESIGN
==================================================

Website WAJIB responsive.

- large typography
- horizontal layouts

- reduce spacing
- adjust grid
- preserve animation

Mobile:
- vertical storytelling
- hamburger menu
- stacked content
- touch-friendly buttons
- reduced particle count
- reduced animation complexity

Jangan hanya mengecilkan desktop layout.

==================================================
25. PERFORMANCE
==================================================

Karena website menggunakan banyak visual dan animation, performance sangat penting.

WAJIB:

- lazy loading image
- optimized image
- WebP/AVIF jika memungkinkan
- preload hanya asset penting
- lazy load video yang tidak berada di initial viewport
- respect prefers-reduced-motion
- jangan membuat animation loop yang tidak diperlukan
- gunakan transform/opacity untuk animation
- hindari layout thrashing
- hindari event listener berlebihan
- cleanup animation/listener saat component unmount

Target:
- smooth scrolling
- minimal jank
- responsive interaction
- cepat pada desktop
- tetap usable pada mobile

44. IMPORTANT DEVELOPMENT RULES
==================================================

1. Jangan langsung coding sebelum audit repository.
2. Jangan merusak fitur existing.
3. Jangan membuat duplicate component.
4. Jangan mengganti dependency tanpa alasan.
5. Jangan menggunakan asset copyrighted secara ilegal.
6. Jangan copy website game lain.
7. Jangan membuat animasi yang menyebabkan lag.
8. Jangan membuat autoplay audio yang mengganggu.
9. Jangan membuat fake functionality yang terlihat nyata.
10. Pastikan semua button memiliki behavior yang jelas.
11. Pastikan semua halaman dapat diakses.
12. Pastikan mobile responsive.
13. Pastikan animation memiliki fallback.
14. Pastikan prefers-reduced-motion didukung.
15. Pastikan console tidak memiliki error.
16. Pastikan tidak ada broken image.
17. Pastikan tidak ada hydration error.
18. Pastikan tidak ada infinite render/effect.
19. Pastikan tidak ada memory leak akibat animation/listener.
20. Jangan mengubah business logic yang tidak berkaitan dengan website.
